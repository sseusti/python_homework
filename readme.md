## 🧪 Тестирование

Для задачи **H-Index II** реализовано отдельное тестирование с использованием `pytest` и `unittest.mock`.

Обычный тест получает тестовые данные из текстового файла:

```text
test → getTestCases() → hIndexTest.txt → hIndex()
```

Mock-тест заменяет источник данных заранее заданными значениями:

```text
test → Mock getTestCases() → тестовые данные → hIndex()
```

При этом алгоритм `hIndex` остаётся настоящим и продолжает выполняться.

### Используемые возможности Mock

В тестах используются:

- `patch` — временная замена зависимости;
- `MagicMock` — Mock-объект, позволяющий задавать поведение зависимости;
- `return_value` — задание возвращаемого значения;
- `side_effect` — имитация возникновения исключения;
- `assert_called_once` — проверка количества вызовов;
- `assert_called_once_with` — проверка количества вызовов и переданных аргументов.

Также с помощью `pytest.raises` проверяется ожидаемое исключение.

Таким образом, Mock позволяет тестировать алгоритм независимо от реального источника тестовых данных и отдельно проверять различные сценарии взаимодействия с зависимостями.
