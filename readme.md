# LeetCode Solutions

Решения задач с [LeetCode](https://leetcode.com/) на Python.

## 📁 Структура

```text
.
├── solutions/
│   ├── 860-lemonadeChange/
│   │   └── solution.py
│   └── ...
├── pyproject.toml
├── .pre-commit-config.yaml
└── README.md
```

Каждая задача находится в отдельной директории, содержит файл `solution.py` и скриншот результата прозождения тестов leetcode.

## 🛠️ Инструменты

* Python 3
* Ruff — линтинг и форматирование кода
* pre-commit — автоматическая проверка перед коммитом

## 🚀 Проверка

Установить зависимости:

```bash
python3 -m pip install ruff pre-commit
```

Установить pre-commit hooks:

```bash
pre-commit install
```

Запустить проверки для всего репозитория:

```bash
pre-commit run --all-files
```
